SpendSmart – Separate HTML and CSS Files

The project contains 5 client-side pages and 5 admin-side pages.
Every HTML page has its own CSS file. Each CSS file is standalone and
includes the shared layout styles, so you do not need a common.css file.

CLIENT SIDE
1. dashboard.html          -> dashboard.css
2. add-expense.html        -> add-expense.css
3. history.html            -> history.css
4. categories.html         -> categories.css
5. profile.html            -> profile.css

ADMIN SIDE
1. admin.html              -> admin.css
2. users.html              -> users.css
3. transactions.html       -> transactions.css
4. admin-categories.html   -> admin-categories.css
5. reports.html            -> reports.css

OPTIONAL
login.html                 -> login.css

HOW TO RUN
1. Extract the ZIP file.
2. Keep all HTML and CSS files in the same folder.
3. Open dashboard.html in your browser for the client side.
4. Open admin.html in your browser for the admin side.
5. Use the navigation links to move between pages.

NOTE
This is a front-end HTML/CSS project with sample data. Forms and management
actions are visual examples; saving real data requires JavaScript and a backend.
